Install in Gmail, use in Mimestream

  1. Click Copy signature. In Gmail, open Settings → See all settings → General → Signature.
  2. Create a signature and paste it into the editor. Choose the correct email address if you have multiple sending addresses.
  3. Under Signature defaults, choose it for new emails, and for replies if desired. Click Save Changes.
  4. In Mimestream → Settings → Signatures, choose the synced Gmail signature for the matching address.

Mimestream syncs Gmail’s default signature for each sending address. Its local “On My Mac” signatures do not support images. Changing this page does not automatically update a signature already pasted into Gmail.
